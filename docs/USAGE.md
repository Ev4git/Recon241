# Recon241 Usage Guide

## Basic Usage

Run a basic scan:

recon241 example.com

## Custom Output Folder

Run scan with custom output folder:

recon241 example.com -o my_reports

## Custom Timeout

Run scan with custom timeout:

recon241 example.com --timeout 15

## Output

Recon241 generates an HTML report at:

reports/recon241_report.html

## Safe Demo Target

For demo or educational testing, use:

example.com

## Ethical Notice

Only scan systems, websites, networks, or applications that you own or have permission to test.
