# Recon241

Recon241 is a beginner-friendly automated reconnaissance and HTML reporting tool built with Python.

**Author:** Ev@

## Features

- Target URL scanning
- HTTP status detection
- Page title extraction
- HTTP header collection
- Link discovery
- Basic security header checks
- Modern terminal output
- Hacker-themed HTML report
